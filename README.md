## 🛠️ 技术哲学与设计准则

* 🏠 **100% Local-First**：用户的数据完全属于用户自己，任何时候都能在离线断网环境下完整工作。
* ⚡ **Zero-Friction**：零安装依赖、零冗余配置，单文件或静态 Web 即开即用。
* 🎯 **Utility-Oriented**：拒绝虚浮假需求与过度包装，只交付真正解决实际痛点的高效工具。
