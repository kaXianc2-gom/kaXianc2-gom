## 🏛 GWY Toolkit — 公考工具箱

8 个纯浏览器端工具，**双击 HTML 即用**，无需安装。所有数据纯本地处理，**绝不上传**。

| 工具 | 作用 | 在线体验 |
|------|------|:--:|
| 🛡️ **DataVeil** | PII 数据脱敏 | [🔗](https://kaxianc2-gom.github.io/data-veil/) |
| 📊 **SheetLens** | 岗位智能筛选+可视化 | [🔗](https://kaxianc2-gom.github.io/sheet-lens/) |
| 📐 **TableNorm** | 表格列名标准化 | [🔗](https://kaxianc2-gom.github.io/table-norm/) |
| ⚖️ **PostCmp** | 岗位深度对比 | [🔗](https://kaxianc2-gom.github.io/post-cmp/) |
| 📅 **AppTrack** | 报名进度追踪 | [🔗](https://kaxianc2-gom.github.io/app-track/) |
| ✏️ **ExamPrep** | 行测刷题+面试模拟 | [🔗](https://kaxianc2-gom.github.io/exam-prep/) |
| 🔍 **PolicySearch** | 政策文件搜索 | [🔗](https://kaxianc2-gom.github.io/policy-search/) |
| 🚀 **GWY LaunchPad** | 统一启动器 | [🔗](https://kaxianc2-gom.github.io/gwy-launchpad/) |

### 数据流

```
TableNorm → DataVeil → SheetLens → PostCmp → AppTrack （→ ExamPrep / PolicySearch）
```

### 设计哲学

- 🏠 **纯本地优先** — 数据不离开你的浏览器
- 📄 **单 HTML 文件** — 下载即用，零依赖
- 🎨 **Apple 风格设计** — 暖砂岩底色 + 毛玻璃
- 🔓 **MIT 开源** — 自由使用、修改、分发
- 🤖 **AI 辅助开发** — Claude (Anthropic) + DeepSeek

### 隐私承诺

所有工具不收集任何数据、不使用遥测、不需要注册。关闭浏览器后数据自动清除。
